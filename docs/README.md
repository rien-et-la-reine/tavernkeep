# Tavernkeep Engineering Documentation

This directory contains the living engineering documentation for Tavernkeep,
the firmware for the Tome embedded device:

- [Requirements](requirements.md) records what Tavernkeep is required or
  intended to do.
- [Architecture](architecture.md) records how Tavernkeep is designed to meet
  those requirements and the rationale behind important structural choices.
- [Validation](validation.md) records evidence that implemented functionality
  behaves as intended.
